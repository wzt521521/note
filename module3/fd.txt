# fd = file descriptor，**文件描述符**

Linux 里一切皆文件：普通文件、管道、socket、终端都统一用 fd 代表。
fd 本质就是一个**非负整数**。

## 核心逻辑

每个进程，内核单独维护一张**文件描述符表**。

- fd 就是这张表的**下标编号**。
- 表里面存指针，指向内核里对应的内核对象（文件 / 管道 / 终端）。

### 三个默认 fd，进程一启动就自带

- fd=0：标准输入 stdin
- fd=1：标准输出 stdout（cout）
- fd=2：标准错误 stderr（cerr）

### 系统调用使用方式

`read(fd, buf, len)` / `write(fd, buf, len)`
你传给 read/write 的 fd 整数，就是让内核去当前进程的 fd 表，用这个下标找到对应的内核资源，然后读写。

fd 表每个进程一份，用来指向内核资源，而非所有栈或者堆资源都用fd表指向，
每次进行调用系统调用，则会传入 fd 下标申请资源，内核根据该进程的 fd 表来找到具体是哪个资源
