当前项目中，客户端找到 Dedicated Server 并加入，可以分成三层：会话发布、局域网发现、网络连接。

### 1. 服务端发布局域网会话

Dedicated Server 进入 Lobby 后创建 `GameSession`，主要配置为：

```cpp
bIsLANMatch = true;
bIsDedicated = true;
bShouldAdvertise = true;
NumPublicConnections = 4;
```

含义是：

- 这是局域网会话；
- 由独立服务器托管；
- 允许被客户端发现；
- 最多允许4个公开连接。

创建成功后，NULL OnlineSubsystem 启动 LAN Beacon，等待客户端的局域网查询。

### 2. 客户端搜索服务器

玩家点击 Join 后调用：

```cpp
FindSessions(10000, true);
```

内部会设置：

```cpp
MaxSearchResults = 10000;
bIsLanQuery = true;
```

这里最重要的是：

```text
服务端：bIsLANMatch = true
客户端：bIsLanQuery = true
```

两边都采用 LAN 模式，客户端才能发现服务端。

### 3. 局域网查询与回复

`FindSessions()` 是异步操作，通信过程是：

```text
客户端广播 LAN 查询包
        ↓
服务器的 LAN Beacon 收到查询
        ↓
服务器检查会话是否还能加入
        ↓
服务器返回会话信息
        ↓
客户端收集返回结果
        ↓
搜索时间结束
        ↓
触发 OnFindSessionsComplete
```

服务器回复的信息包括：

- 服务器地址和游戏端口
- 会话人数和剩余空位
- 会话设置
- `MatchType`
- 会话是否允许加入

客户端每收到一个回复，就生成一个 `FOnlineSessionSearchResult`，放入：

```cpp
LastSessionSearch->SearchResults
```

搜索结束后，结果数组通过下面的调用链返回项目代码：

```text
OnFindSessionsComplete
→ UMultiplayerSessionsSubsystem::OnFindSessionsComplete
→ UMenu::OnFindSessions
```

### 4. 客户端选择服务器

当前 Dedicated Server 模式没有复杂的匹配规则。

客户端遍历搜索结果，直接选择第一个结果：

```cpp
MultiplayerSessionsSubsystem->JoinSession(Result);
```

所以这里的“匹配”实际是：

> 在局域网里找到一个可加入的服务器，然后选择它。

没有涉及段位、地区、延迟阈值或者服务器负载匹配。

### 5. 加入会话并取得地址

`JoinSession()` 会将搜索结果中的服务器地址保存到客户端本地的 `GameSession`。

加入完成后触发：

```text
OnJoinSessionComplete
→ UMenu::OnJoinSession
```

然后客户端调用：

```cpp
GetResolvedConnectString(NAME_GameSession, Address);
```

得到类似这样的连接地址：

```text
192.168.1.20:7777
```

需要注意：

> `JoinSession()` 成功只表示会话层处理成功，并不表示客户端已经真正连接到游戏服务器。

### 6. 真正连接服务器

拿到地址后，客户端调用：

```cpp
PlayerController->ClientTravel(
    Address,
    ETravelType::TRAVEL_Absolute
);
```

从这一步开始，UE 才建立真正的网络连接：

```text
ClientTravel
→ 创建 PendingNetGame
→ 创建 IpNetDriver
→ 连接服务器的 IP:7777
→ 网络版本检查
→ 客户端提交登录信息
→ 服务器执行 PreLogin
→ 客户端加载服务器当前地图
→ 客户端发送 Join
→ 服务器创建 PlayerController 和 PlayerState
→ 服务器执行 PostLogin
```

当服务器执行：

```cpp
ALobbyGameMode::PostLogin()
```

才表示这个客户端已经真正进入服务器大厅。

### 7. 大厅人数满足后进入比赛

每个客户端加入后，Lobby 服务器都会统计当前人数。

达到目标人数后：

```cpp
World->ServerTravel(GameMapPath);
```

服务器切换到正式比赛地图，并把已经连接的客户端一起带过去。

完整主线可以记为：

```text
服务端创建并广播 LAN 会话
        ↓
客户端 FindSessions
        ↓
客户端广播查询
        ↓
服务器返回会话信息
        ↓
OnFindSessionsComplete
        ↓
选择第一个结果
        ↓
JoinSession
        ↓
解析服务器 IP:Port
        ↓
ClientTravel
        ↓
UE 完成网络登录和地图加载
        ↓
服务器 PostLogin
        ↓
客户端正式进入 Lobby
        ↓
人数满足后 ServerTravel 进入比赛
```
