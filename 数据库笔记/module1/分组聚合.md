### SQL 执行过程拆解

**原始 SQL 语句**
```sql
SELECT
    e.id,
    e.full_name,
    COUNT(ep.project_id) AS project_count
FROM employees AS e
LEFT JOIN employee_projects AS ep
    ON ep.employee_id = e.id
GROUP BY e.id, e.full_name
ORDER BY e.id;
```

```sql
SELECT
    p.project_code,
    p.name AS project_name,
    COUNT(ep.employee_id) AS employee_count,
    COALESCE(SUM(ep.allocation_percent), 0) AS total_allocation,
    ROUND(COALESCE(AVG(ep.allocation_percent), 0), 2) AS average_allocation
FROM projects AS p
LEFT JOIN employee_projects AS ep
    ON ep.project_id = p.id
GROUP BY
    p.id,
    p.project_code,
    p.name
ORDER BY p.id;
```
这3个聚合函数什么意思

答复：
### 三个聚合函数的含义（结合当前SQL场景）
这条SQL通过左连接按项目分组统计，三个函数都是针对**单个项目分组内**的员工分配数据计算，作用如下：

1.  **COUNT(ep.employee_id) AS employee_count**
    统计每个项目的参与员工人数。
    - `COUNT(列名)` 的特性是只统计该列**非NULL**的行数；
    - 因为是`LEFT JOIN`，没有员工参与的项目，`ep.employee_id` 为NULL，不会被计数，最终无人参与的项目结果为0。

2.  **COALESCE(SUM(ep.allocation_percent), 0) AS total_allocation**
    计算每个项目的总人力投入占比，无人参与则显示0。
    - `SUM(ep.allocation_percent)`：对分组内所有员工的人力分配比例求和；
    - `COALESCE(..., 0)`：如果求和结果为NULL（项目没有员工，所有关联值都是NULL，SUM结果为NULL），就自动替换成0，避免结果出现NULL。

3.  **ROUND(COALESCE(AVG(ep.allocation_percent), 0), 2) AS average_allocation**
    计算每个项目的平均人力分配比例，保留2位小数，无人参与则显示0.00。
    - `AVG(ep.allocation_percent)`：对分组内所有员工的人力分配比例求平均值；
    - 内层`COALESCE(..., 0)`：把无员工项目的NULL结果替换成0；
    - 外层`ROUND(..., 2)`：将最终结果四舍五入，固定保留2位小数。

```sql
    e.employee_no,
    e.full_name,
    d.name AS department_name,
    e.salary
FROM employees AS e
JOIN departments AS d
    ON d.id = e.department_id
WHERE e.salary > (
    SELECT AVG(e2.salary)
    FROM employees AS e2
    WHERE e2.department_id = e.department_id
)
ORDER BY e.id;
```

CTE
```sql
WITH department_salary_stats AS (
    SELECT
        department_id,
        COUNT(*) AS employee_count,
        AVG(salary) AS average_salary
    FROM employees
    GROUP BY department_id
)
SELECT
    e.employee_no,
    e.full_name,
    d.name AS department_name,
    e.salary,
    stats.average_salary
FROM employees AS e
JOIN departments AS d
    ON d.id = e.department_id
JOIN department_salary_stats AS stats
    ON stats.department_id = e.department_id
WHERE e.salary > stats.average_salary
ORDER BY e.id;
```
