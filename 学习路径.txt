free list → first fit → block split → adjacent block merge

**模块完成标准：**别人问 “malloc 怎么来的”，你不仅能回答，而且能拿出程序证明 brk/mmap、泄漏、UAF、碎片这些现象。

模块 4：基础 Socket 网络编程

这一模块先不要碰 epoll，先把 socket API 真正写熟。

4.1 TCP Echo Server	socket → bind → listen → accept → recv → send	TCP 服务端生命周期

4.3 netcat 测试	nc 127.0.0.1 8888	快速测试
4.4 多客户端	一个连接一个线程	Thread-per-Connection
4.5 UDP Server	recvfrom/sendto	TCP/UDP 差异
4.6 Non-blocking	fcntl (fd, F_SETFL, O_NONBLOCK)	非阻塞 IO
4.7 EAGAIN	主动制造无数据可读	非阻塞语义
4.8 Short Read	一次发送大数据并限制每次 recv	短读
4.9 Short Write	大量发送数据观察部分发送	短写
4.10 FIN/RST	主动关闭客户端、异常断开	TCP 状态

这一阶段一定要形成意识：

send () != 一定全部发送
recv () != 一定收到完整消息
一次 send != 对方一次 recv
