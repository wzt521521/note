主程序
int main()
{
    const size_t MB = 1024 * 1024;

    std::cout << "PID: " << getpid() << std::endl;

    for (int i = 0; i < 100; ++i) {
        char* p = new char[10 * MB];

        // 真正触碰内存，避免只增加虚拟地址而 RSS 不明显增长
        for (size_t j = 0; j < 10 * MB; j += 4096) {
            p[j] = 1;
        }

        std::cout << "allocated " << (i + 1) * 10
                  << " MB, press Enter..." << std::endl;

        std::cin.get();

        // 故意不 delete[]
        // delete[] p;
    }

    return 0;
}

上一轮申请的那 10 MB 没有 delete[]，而下一轮循环又让 p 指向了新的地址。旧地址丢失后，那块内存仍然属于这个进程，但程序已经没有正常途径再释放它，此即memory leak。
