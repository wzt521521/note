主程序如下：
int main()
{
    const size_t MB = 1024 * 1024;
    const size_t size = 256 * MB;

    std::cout << "PID: " << getpid() << '\n';

    char* p = (char*)malloc(size);
    if (!p) {
        std::cerr << "malloc failed\n";
        return 1;
    }

    std::cout << "allocated 256 MB, press Enter..." << std::endl;
    std::cin.get();

    long page_size = sysconf(_SC_PAGESIZE);
    std::cout << "page size: " << page_size << " bytes\n";

    for (size_t i = 0; i < size; i += page_size) {
        p[i] = 1;
    }

    std::cout << "touched every page, press Enter..." << std::endl;
    std::cin.get();

    free(p);
}

ps指令：ps -o pid,vsz,rss,min_flt,maj_flt -p <PID>

观察结果：
ubuntu@wzt:~$ ps -o pid,vsz,rss,min_flt,maj_flt -p 6019
    PID    VSZ   RSS  MINFL  MAJFL
   6019 268504  3264    146      0

ubuntu@wzt:~$  ps -o pid,vsz,rss,min_flt,maj_flt -p 6019
    PID    VSZ   RSS  MINFL  MAJFL
   6019 268504 265344 65682      0

vsz几乎瞬间增长，但是rss第二次才增长，说明了一个现象，虚拟内存的出现，让物理内存按首次访问按页落实
注意，这里分配的应该是真实的物理内存而非mmap的映射（申请是逐步申请4KB的内存，而非一口气申请256MB）
