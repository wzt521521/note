主代码:
```cpp
int main()
{
    int* p = new int[10];

    for (int i = 0; i < 10; ++i) {
        p[i] = i;
    }

    std::cout << "p[9]  = " << p[9] << '\n';

    // 越界：合法下标只有 0 ~ 9
    p[10] = 12345;

    std::cout << "p[10] = " << p[10] << '\n';

    delete[] p;
    return 0;
}
```
输出：
p[9]  = 9
p[10] = 12345

解释：
越界了，但程序没有崩。 p[10] = 12345 已经是未定义行为，只是这次越界地址碰巧还落在当前进程可读写的 heap 页面里，所以 CPU/内核没有理由立刻报错。p[10] 对应的地址虽然已经超出了这个 C++ 数组对象的合法范围，但它很可能仍然落在一个当前进程拥有、并且带有读写权限的虚拟内存页里，所以 MMU/OS 不会因为“数组越界”而阻止你。
